# 沿海台风实况与预警网站

面向沿海居民，集中回答：台风叫什么、目前在哪、往哪走、风力多大，以及我所在地区有什么官方预警。

当前阶段：已提供静态网站原型，并接入台风路径资料的自动更新流程。

- [项目计划书](docs/项目计划书.md)：用户需求、页面规划、分级预警、数据方案、开发排期与验收标准。
- [实施任务清单](docs/实施任务清单.md)：按阶段推进的工作项。

## 数据与更新

- 台风路径资料：浙江省水利厅的[浙江省台风路径实时发布系统](https://typhoon.slt.zj.gov.cn/)。
- 自动更新：GitHub Actions 每 15 分钟尝试抓取一次，仅在数据变化时提交 `data/typhoon.json`；GitHub 的定时工作流可能因平台负载延迟运行，因此不承诺精确到整点 15 分钟。
- 页面会显示资料时间与本站抓取时间。没有活动台风或抓取失败时，页面明确显示不可用状态；抓取失败会保留上一次成功数据。
- 预警模块仍是演示内容，不能作为正式预警或防灾决策依据。上线正式预警前必须接入并核验当地气象主管机构的授权来源。

初始范围：中国大陆沿海地区，简体中文，手机优先。首个试点城市、数据服务供应方及部署平台在实施前确定。

预警等级与内容以当地气象部门正式发布为准。实况、预报、历史数据和数据不可用状态必须明确区分。
